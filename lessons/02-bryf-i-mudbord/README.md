# Урок 2. Бриф і мудборд

**Програма:** Inkscape 1.4

На цьому уроці ви з’ясуєте, **для кого** ваш бренд і **яким** він має бути, а потім зберете це на одному аркуші — мудборді: фото, палітра з 3 кольорів, 2 шрифти, 3 прикметники.

## Результат уроку

| Файл | Що в ньому |
|---|---|
| `brief.pdf` (або заповнений паперовий бланк) | Відповіді на питання брифу, підпис викладача |
| `moodboard.svg` | 6 зображень, 3 кольори з HEX-кодами, 2 шрифти, 3 прикметники, аудиторія |

**Контрольна точка:** викладач затверджує бриф (30–40 с на кожного). Поки викладач не підійшов, бриф перевіряє ваша пара.
