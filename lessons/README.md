# Бренд за день: уроки

Покрокові уроки до шестигодинного воркшопу «Бренд за день». Кожен здобувач створює повний фірмовий стиль вигаданого стартапу — від брифу до файлів для друкарні — у безкоштовних програмах **Inkscape 1.4**, **Krita 6** і **Scribus 1.6**.

Скриншоти зроблено в англійському інтерфейсі програм; назви меню перекладено в тексті. Наскрізний приклад — бренд кава-фургона **«КавоБус»**, усі його файли лежать у {{asset example/}}.
